🎯 PRÓXIMOS PASOS
================================================================================

1️⃣ INSTALAR TESSERACT EN TU COMPUTADORA
   
   Windows PowerShell:
   > .\install_tesseract_windows.ps1
   
   O manual desde:
   https://github.com/UB-Mannheim/tesseract/wiki

2️⃣ INSTALAR DEPENDENCIAS PYTHON
   
   > pip install pytesseract Pillow

3️⃣ PREPARAR IMAGEN DE PRUEBA
   
   - Guarda tu captura de pantalla bancaria como:
     test_image_bank_app.jpg
   
   - Colócala en:
     penny-expense-processor\lambda-python3.12\

4️⃣ EJECUTAR PRUEBA LOCAL
   
   > cd penny-expense-processor\lambda-python3.12
   > python test_tesseract_local.py
   
   Resultado esperado:
   ✅ Found 7-8 transactions
   ✨ TEST PASSED

5️⃣ DEPLOY A AWS
   
   > sam build
   > sam deploy
   
   Nota: Primera build tardará ~5-10 minutos

6️⃣ VERIFICAR EN PRODUCCIÓN
   
   - Envía foto de prueba por Telegram
   - Verifica que transacciones aparezcan en Google Sheets
   - Monitorea logs:
     > aws logs tail /aws/lambda/penny-expense-processor --follow

================================================================================
🆘 SOPORTE Y TROUBLESHOOTING
================================================================================

❌ "tesseract is not installed"
   → Ejecuta: tesseract --version
   → Si falla: .\install_tesseract_windows.ps1

❌ "No transactions found"
   → Verifica que la imagen sea clara
   → Revisa texto extraído en output del test
   → Ajusta PSM mode en tesseract_client.py

❌ Build de SAM falla
   → Limpia cache: Remove-Item -Recurse -Force .aws-sam
   → Rebuild: sam build --use-container

🔄 Rollback a Textract
   → Ver sección completa en MIGRATION_SUMMARY.md
   → Restaurar imports y permisos IAM
   → Rebuild y deploy
